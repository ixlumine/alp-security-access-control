Token ditandatangani oleh server saat autentikasi valid dan dikirimkan pada setiap request melalui header Authorization: Bearer <token>.

Mekanisme Autentikasi

Sistem menggunakan arsitektur Stateless Token-based Security dengan proteksi tampering berbasis cryptographic signature.

  • Header: Menentukan tipe token JWT dan algoritma signing HMAC-SHA256.
  • Payload: Menyimpan claims identitas (`id`, `username`, `role`, `tier`, `is_verified`).
  • Signature: Memvalidasi integritas. Jika token diubah sengaja (Tampered), server merespons 403 Forbidden.
RBAC (Role-Based Access Control): Hak akses ditentukan murni berdasarkan role pengguna (`admin`, `seller`, `customer`) melalui middleware requireRole() & requirePermission().
